RP Russia 196 — Login Fix V9

ИСПРАВЛЕНИЕ: вместо непонятной ошибки Unexpected token при регистрации/входе показывается объяснение, если сервер /api не запущен.

ВАЖНО: это полноценный Node.js сайт, а НЕ статический сайт Vercel.
1. Распакуйте ZIP.
2. Загрузите index.html, server.js и package.json в корень GitHub (не ZIP).
3. В Railway подключите репозиторий и запустите npm start.
4. Откройте публичный домен Railway. Регистрация/вход используют /api на этом же домене.
5. Для постоянных аккаунтов: Railway Volume, переменная DATA_DIR=/data.

Если опубликовать только index.html на Vercel, регистрация и онлайн НЕ заработают. Для Vercel потребуется отдельная серверная архитектура.

Не используйте один общий публичный админ-код как единственный способ защиты: права должны проверяться на сервере.
